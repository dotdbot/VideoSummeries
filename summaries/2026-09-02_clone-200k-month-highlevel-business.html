1
Create a sub-account — In your GoHighLevel agency view, go to Sub Accounts → Create Sub Account → search "roofing" → pick "Home Services Roofing" template. Search Google for a real roofing business and use their info as a demo client.
2
Add a local phone number — Switch to the sub-account view → Settings → Phone System → Add Number → pick a number matching the roofer's area code. Cost: $1.15/month. Have the roofer forward their personal cell to this new number.
3
Set up call forwarding — Forward calls to their cell. Set 20-second ring timeout. Toggle voicemail OFF (critical — if voicemail is on, call registers as answered and the automation never fires).
4
Create workflow from template — Go to Automations → Create Workflow → Select from Template → search "Missed Call Text Back" → pick the template with 13,000+ uses. Enable auto-save. Workflow: Call missed → slight delay (0.2 hrs feels human) → assign user → send SMS → GoHighLevel notification.
5
Create a booking calendar — Calendars → New → choose "Roof Inspection." Copy the shareable calendar link.
6
Set the SMS text — Back in the workflow: "Sorry I missed your call. How can we help? Would you like us to come out and inspect your roof? Book here: [calendar link]." Save. Publish.
7
Demo to the roofer — Call their number, don't pick up. In 12 seconds they get a text with a live calendar link. 90-second demo. Close the deal.
